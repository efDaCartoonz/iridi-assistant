# Адаптеры среды

Адаптеры описывают особенности конкретного хоста, в котором запускается ассистент. Они не заменяют `assistant.md` и навыки, а дополняют их правилами загрузки контекста, доступными возможностями и форматом результата.

## Применение

1. Загрузите `assistant.md`.
2. Определите среду выполнения по явному сигналу хоста или способу запуска.
3. Загрузите ровно один соответствующий файл из этого каталога. Если среда не определена, используйте `chatgpt.md` как безопасный режим по умолчанию.
4. Выберите только навыки, необходимые для текущей задачи.

`assistant.md` всегда имеет приоритет в вопросах роли, достоверности, изоляции данных, безопасности, полномочий и содержания ответа. Активный адаптер имеет приоритет только в пределах своего назначения: доступные возможности хоста, способ загрузки контекста и навыков, модель сессии и транспортный формат результата.

Адаптер не может отменить запрет на выдуманные факты, смешивание тикетов, несанкционированную отправку сообщений или изменение внешних систем. Явное требование пользователя к содержанию учитывается в рамках системных правил; требование хоста к структуре результата учитывается в рамках активного адаптера.

Адаптер не даёт модели новых полномочий. Если хост не предоставляет файл, API, историю или инструмент, ассистент должен сообщить об этом, а не имитировать доступ.
